# KarigarPro

Carpenters ke liye hisab kitab ki website — mazdoori (unchai × chorai, sq ft), material ka kharcha, PDF/Text bill, aur purane hisab, sab kuch aik jagah.

**Live website:** https://karigarpro.vercel.app

## Features

- **Naya Hisab** — customer ka naam, naap (feet + inches), aik se zyada kaam aik saath (Wardrobe + Kitchen waghera), mazdoori live hisab
- **Material ka Kharcha** — har material ki asal photo, quantity +/−, aur har rate direct editable (khud save ho jata hai)
- **Sheets sab se pehle** — Lamination Sheet aur UV Sheet materials me sab se oopar
- **PDF / Text Bill** — poori tafseel ke saath: material kitna laga aur kya rate, mazdoori, extra kharcha, advance, baqi balance
- **Purane Hisab** — save shuda hisab, search aur delete ke saath
- **Mere Rates** — har carpenter apne mazdoori rates khud set kare

Data sirf browser me save hota hai (localStorage) — koi server ya login nahi.

## Files

- `index.html` — poori website (aik hi file)
- `logo.jpg`, `favicon.jpg` — KarigarPro logo
- `mat-*.jpg` — materials ki asal photos
